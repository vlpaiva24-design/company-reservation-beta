# Бронь компаний — Beta

Практичное full-stack приложение для совместного бронирования юридических лиц командами **Таллин**, **Токио**, **Вавилон**, **Сеул**. Node.js 24, встроенный `node:sqlite`, без внешних зависимостей и платных сервисов.

## Запуск

```bash
cd /Users/vladimir/.openclaw/workspace/company-reservation-beta
npm start
```

Откройте <http://localhost:3000>. При первом запуске создаётся пустая база `data/companies.db`.

### Необязательные демо-данные

```bash
npm run seed
```

Seed идемпотентен по ИНН. Для разработки: `npm run dev`. Для тестов: `npm test`.

## Возможности

- выбор текущей команды (beta вместо авторизации);
- добавление, просмотр и редактирование компаний;
- глобальный поиск по всем полям, статусу и команде;
- фильтры по статусу и забронировавшей команде;
- атомарное бронирование через транзакцию SQLite и условный UPDATE;
- освобождение только командой-владельцем;
- история создания, изменений, бронирования и освобождения;
- серверная валидация, параметризованные SQL-запросы, безопасный вывод через `textContent`;
- адаптивный интерфейс для телефона и рабочего стола.

ИНН обязателен и уникален, но намеренно не ограничен российской длиной: допускаются цифры, буквы и стандартные разделители для международных идентификаторов.

## Настройки

- `PORT` — порт (по умолчанию 3000)
- `DB_PATH` — путь к SQLite-файлу

## API

- `GET/POST /api/companies`
- `GET/PUT /api/companies/:id`
- `POST /api/companies/:id/reserve`
- `POST /api/companies/:id/release`
- `GET /api/companies/:id/history`

Для reserve/release команда передаётся как JSON `{"team":"Таллин"}`.
